# RSS Feed v0.1.0

Your feeds, at home on Omarchy.

![RSS Feed running on my XPS](https://raw.githubusercontent.com/tcballard/omarchy-plugin-rss-feed/b786eb40fc137ba89983573e854dbf30371e18c5/preview.png)

I built this reader for Omarchy itself. It now has its own home as a plugin, so it can improve without waiting for an upstream shell release.

Browse headlines on the left and read the story on the right. Keep it tiled into your workspace or open it as a centred floating window. RSS Feed remembers your choice.

- Follow Omarchy announcements, choose from ten included technology feeds, or add your own RSS and Atom subscriptions.
- Organise sources into named collections, track unread stories and read cached articles offline.
- Use the mouse or keyboard, with an optional **Super + Alt + N** shortcut.
- Keep the reader in your Omarchy colours, with links to open stories at their original publishers.

The first version also includes bounded feed requests, safe article markup and recovery from broken feeds. Portable tests cover parsing, collections, persistence, shortcuts, window placement and hostile input.

## Install

Requires Omarchy Quattro with plugin support and Python 3.12+. [Full requirements and removal instructions](https://github.com/tcballard/omarchy-plugin-rss-feed#install).

```bash
omarchy plugin add https://github.com/tcballard/omarchy-plugin-rss-feed.git --enable
python3 ~/.config/omarchy/plugins/io.github.tcballard.rss-feed/scripts/keybindings.py
```

The second command installs the optional shortcut. It checks for conflicts and backs up your bindings first.

Already installed?

```bash
omarchy plugin update io.github.tcballard.rss-feed
omarchy-restart-shell
```

These commands follow the repository's default branch. The versioned source is available through the release tag once published.
