### Maintainer notes

RSS Feed is a native two-pane reader with RSS/Atom subscriptions, collections, cached reading and remembered tiled/centred floating mode. Requires the Omarchy Quattro plugin-capable shell, Lua-enabled Hyprland, Python 3.12+, system CA certificates and coreutils; no pip packages. Direct HTTPS requests go only to enabled feed publishers. Runs with normal user permissions. The optional shortcut setup is explicit, checks conflicts and backs up bindings.lua. Removal instructions and retained-data details are in the README and docs/security.md. Version 0.1.0 is an untagged candidate. Portable validation and adversarial fixtures pass; the maintainer confirmed opening/floating on an XPS before hardening. The root preview is the maintainer-supplied screenshot of RSS Feed. Full host lifecycle checks remain pending; see docs/validation.md. This is a preparation draft, not a request for approval or listing yet.
