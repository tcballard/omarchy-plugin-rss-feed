# Security reporting

RSS Feed is a desktop plugin running with your normal user permissions. It is not a sandbox. Read [the capability and data notes](docs/security.md) before installing.

For a suspected vulnerability, use [GitHub’s private vulnerability reporting](https://github.com/tcballard/omarchy-plugin-rss-feed/security/advisories/new) if enabled. If that option is unavailable, open an issue asking for a private reporting channel without including exploit details, private feed URLs or personal data. Do not post secrets in public issues.

Include the plugin commit, Omarchy revision, affected behaviour and a minimal fictional reproducer. The current main-branch candidate is maintained; no tagged release or security-support lifetime is promised yet.
